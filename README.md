O proposta projeto: 
Elaborar uma análise empírica para comparar os diferentes métodos de ordenação de forma criativa. 

Qual a nossa ideia criativa?:
Pensamos em outras estruturas de dados que poderíamos usar no lugar de valores inteiros. 
Escolhemos 'Imagem'  como estrutura. 

Isso nos leva a pensar: 
Quais os critérios de comparação entre essa estrutura de dados (imagem) que podemos utilizar a fim de conseguir ordenar um conjunto?. 

Avaliaremos com base em 4 propriedades de uma imagem que podem ser avaliadas numericamente a fim de permitir uma comparação:
* A. Luminosidade Média (Brightness / Luminance) 
* B. Tonalidade Predominante (Hue / Matiz) 
* C. Saturação (Vivacidade da Cor) 
* D. Complexidade Visual (Entropia ou Densidade de Bordas)
